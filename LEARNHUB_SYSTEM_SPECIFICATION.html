🎓 LEARNHUB ACADEMY
Official Comprehensive Architecture, Modules & Functional Specification Manual

1. Executive Summary & Purpose

LearnHub is a full-stack, enterprise-grade Learning Management System (LMS) built to deliver high-quality, barrier-free technical education. It features interactive curriculum browsing, real-time video classrooms, progress tracking, automated printable certificate issuance, an administrative suite with soft delete, LIFO data ordering, and dynamic CAPTCHA security.

2. Technology Stack & Architecture

Tier / Component Technology Role & Responsibility
Frontend SPA React 18 + Vite Fast single-page application with responsive layouts and fluid state management.
Design & Styling Vanilla CSS + Material Design Tokens Custom design system with Google Plus Jakarta Sans typography and glassmorphic UI.
Backend API Server Node.js + Express.js RESTful API managing authentication, CRUD modules, reports, and security middleware.
Database (Primary) MongoDB Atlas Cloud Mongoose-backed persistence for Users, Courses, Enrollments, and Certifications.
Database (Fallback) Persistent JSON Store Zero-downtime offline fallback mechanism ensuring high availability.
Security & Auth JWT + Bcrypt.js + Cookies Secure password hashing, signed access tokens, and HTTP-only cookie support.
Anti-Bot Security Dynamic SVG CAPTCHA Cryptographically signed distorted visual challenges on all forms.

3. Complete Page-by-Page Breakdown

1. Landing Page (/ • HomePage.jsx)

  • Showcases platform branding, value propositions, and learner community metrics.
  • 6 Static Curated Popular Courses: Fixed premium cards with ratings, tech tags, and 1-click redirection to the course catalog.
  • Category filter shortcuts (Computer Science, Data Science, Design, Business).

2. Course Catalog & Search (/courses • CourseListingPage.jsx)

  • Live searchable catalog displaying all courses published by admins in the database.
  • Multi-facet filtering: Category, Level (Beginner / Intermediate / Advanced), and Pricing.
  • Responsive 6-item pagination and instant course application modal.

3. Classroom & Video Player (/player • VideoPlayerPage.jsx)

  • Distraction-free learning room with embedded YouTube streaming lectures.
  • Curriculum accordion with real-time lesson progress checkmarks.
  • Automated Certificate of Completion: Generated dynamically upon 100% course completion.

4. Student Dashboard (/dashboard • StudentDashboardPage.jsx)

  • Overview of enrolled courses, completed hours, and active certifications.
  • 1-Click "Resume Learning" button taking students directly back to their current lesson.

5. Authentication Suite (/login, /register, /forgot-password)

  • Login Page: Email/Password login guarded with mandatory dynamic CAPTCHA. Demo buttons prefill credentials without skipping CAPTCHA.
  • Register Page: Form validation with CAPTCHA, redirecting to login with prefilled credentials.
  • Forgot Password Page: CAPTCHA-protected password recovery requests.

6. Admin Control Center (/admin)

  • Admin Dashboard (/admin): Real-time platform KPI metrics and category distribution.
  • Course Management (/admin/courses): Course CRUD with 50+ instant presets, soft delete, and LIFO ordering.
  • User Management (/admin/users): User account CRUD, role modification, soft delete, and LIFO ordering.
  • Enrollment Applications (/admin/enrollments): Student applications and manual enrollment tools.
  • Reports & Audit (/admin/reports): Exportable intelligence reports with RFC-4180 CSV generation and printable letterhead PDF layouts.

7. Contact & Support Center (/contact • ContactPage.jsx)

  • Direct support form with inquiry categorization and CAPTCHA spam protection.
  • Frequently Asked Questions (FAQ) reference guide.

4. Key Security & Operational Highlights

  • LIFO (Last-In, First-Out) Sorting: All admin tables show newly created items at the very top.
  • Non-Destructive Soft Delete: Records are flagged with isDeleted: true to maintain database integrity.
  • Stateless CAPTCHA Tokens: Signed with JWT (10-minute expiry), eliminating server memory leaks.
  • Single-Port Universal Deployment: Express serves both API and compiled React SPA bundle.
