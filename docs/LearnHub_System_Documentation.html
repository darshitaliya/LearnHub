1 Executive Overview & Platform Summary

LearnHub is a next-generation, cloud-native Learning Management System (LMS) and e-learning platform designed to deliver an engaging, high-performance education experience for students, educators, and enterprise administrators.

🎓 For Students

Self-paced video classroom, multi-factor course filtering, direct enrollment, interactive curriculum progression, certificate tracking, and personal profile management.

👨‍🏫 For Instructors

Comprehensive course authoring tools, dynamic curriculum builder, lesson video embedding, enrolled student monitoring, and rating analytics.

🛡️ For Platform Admins

Centralized command center with real-time KPI metrics, global user management (roles & permissions), course publishing moderation, enrollment audits, and revenue reports.

⚡ Zero-Latency Fallback Architecture

LearnHub includes an automated dual-mode storage engine: when local MongoDB server instances are active, it connects seamlessly; in environments where MongoDB is offline, it activates an Adaptive In-Memory Database Store with JSON disk synchronization to guarantee 100% continuous uptime without configuration barriers.

4 RESTful API Reference Specification

The LearnHub backend provides a clean, predictable REST API that returns standardized JSON structures. All requests requiring authentication must pass the bearer token in the Authorization: Bearer <token> header.

Authentication & Profile Endpoints

Method Endpoint Access Level Description & Payload
POST /api/auth/register Public Registers a new student account. Body: { name, email, password, phone }
POST /api/auth/login Public Authenticates user and returns JWT token & user profile. Body: { email, password }
GET /api/auth/me JWT Auth Fetches current authenticated user's session profile, wishlist, and enrollments.
PUT /api/auth/profile JWT Auth Updates user personal details (name, phone, bio, avatar URL).
POST /api/auth/logout Public Invalidates client session tokens.

Course & Catalog Endpoints

Method Endpoint Access Level Description & Payload
GET /api/courses Public Returns list of all active courses with optional query parameters (category, level, search).
GET /api/courses/:id Public Fetches deep details, syllabus modules, lessons, and instructor profile for a course ID.
POST /api/courses/:id/enroll JWT Auth Enrolls the authenticated student into the course and initializes progress record.
POST /api/courses Admin Creates a new course with nested curriculum modules and lesson definitions.
DELETE /api/courses/:id Admin Deletes course and removes it from user enrollment indices.

Learning Progress & Admin Endpoints

Method Endpoint Access Level Description & Payload
GET /api/progress/:courseId JWT Auth Retrieves completed lesson IDs, percentage completed, and certificate issuance status.
POST /api/progress/lesson-complete JWT Auth Marks a lesson as completed, recalculates completion %, and updates last watched position.
GET /api/admin/stats Admin Returns aggregate metrics: Total Revenue, Total Students, Active Courses, Completion Rates.
GET /api/admin/users Admin Returns all registered platform users with roles, enrollment counts, and registration dates.
PUT /api/admin/users/:userId/role Admin Elevates or adjusts user role (student, instructor, admin).
DELETE /api/admin/users/:userId Admin Deactivates user record and clears session tokens.
GET /api/admin/enrollments Admin Fetches platform-wide active student course enrollments.

5 Security & Role-Based Access Control (RBAC)

Security is implemented at both the network boundary and within the application layer through defense-in-depth methodologies.

🔐 JWT Bearer Tokens

Signed using high-entropy secrets, encapsulating user ID, email, and role claims. Tokens are verified on every protected API call via Express middleware.

🛡️ BCrypt Password Security

Zero plain-text password storage. All user credentials undergo 10 rounds of cryptographic salting and hashing before persisting.

🚦 RBAC Route Guards

Double-layer route protection: Client-side <ProtectedRoute> components prevent unauthorized DOM views, while backend middleware rejects unauthorized API calls with 403 Forbidden.

7 User Guides (Student, Instructor, Admin)

👨‍🎓 7.1 Student User Guide

  1. Account Creation & Login: Navigate to /register to sign up or use /login with pre-configured student demo credentials (alex@learnhub.com / student123).
  2. Browsing & Enrolling: Go to the Course Catalog, filter by category or search terms, and click Enroll Now on any course details page.
  3. Active Learning: Visit My Courses or Dashboard and click on any course to open the Video Classroom. Check off completed lessons to update progress in real time.
  4. Profile Customization: Update profile bio, phone number, and avatar under /profile.

👨‍🏫 7.2 Instructor User Guide

  1. Instructor Authentication: Sign in with instructor credentials (elena@learnhub.com / instructor123).
  2. Curriculum Management: Access courses to view active course metrics and student engagement levels.
  3. Authoring Courses: Construct lessons, assign streaming video URLs, configure pricing, and submit courses for publishing.

🛡️ 7.3 Administrator Operations Guide

  1. Admin Portal Access: Log in using administrator credentials (admin@learnhub.com / admin123) to access /admin.
  2. User Management (/admin/users): View registered users, promote users between roles, or deactivate accounts.
  3. Course Moderation (/admin/courses): Publish new courses, modify curriculum data, or remove outdated content.
  4. Enrollments & Financial Audit (/admin/enrollments & /admin/reports): Inspect total platform revenue, active enrollments, and student trends.

8 Installation, Deployment & Operations Guide

Prerequisites

  • Node.js: v18.0.0 or higher (v20+ / v24+ recommended)
  • NPM: v9.0.0 or higher
  • MongoDB: Optional (Local MongoDB server or MongoDB Atlas URI; system automatically utilizes zero-config in-memory persistence when MongoDB is offline).

Step-by-Step Local Setup

1. Clone & Install Dependencies
# Clone repository
cd LearnHub

# Install Backend Dependencies
cd server
npm install

# Install Frontend Dependencies
cd ../client
npm install
2. Environment Configuration (server/.env)
PORT=5000
MONGODB_URI=mongodb://127.0.0.1:27017/learnhub
JWT_SECRET=learnhub_super_secret_jwt_key_2026
NODE_ENV=development
3. Launch Servers
# In Terminal 1 - Start Backend (Port 5000)
cd server
node index.js

# In Terminal 2 - Start Frontend (Port 3000)
cd client
npm run dev
